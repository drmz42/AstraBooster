# Contributing

AstraBooster is intentionally small and model-agnostic.

Before proposing an addition, describe the concrete user failure mode, the outcome it improves, and why the existing core or specialist references do not already cover it.

Prefer a minimal change to the relevant reference over expanding the main SKILL.md. Keep tests deterministic, independent of paid services and safe on developer machines.

For changes to the execution protocol, include a repeatable scenario, the intended acceptance criterion, and any trade-offs in context size, autonomy or risk.

Do not submit secrets, private VPS configuration, customer records, copied proprietary prompt files or unlicensed upstream material.

Contributions are reviewed under the repository's MIT licensing terms.
