# Необязательное дополнение к правилам проекта

Для сложных задач с интеграциями и пользовательскими действиями можно применять установленный скилл `astra-booster`. Сначала определить наблюдаемый результат, затем выполнить соразмерную риску проверку и сообщить фактически подтверждённый уровень готовности. Все существующие ограничения доступа, безопасности и деплоя имеют приоритет.

**Не перезаписывать действующий AGENTS.md.** Встраивать только нужные формулировки с согласия владельца проекта.
